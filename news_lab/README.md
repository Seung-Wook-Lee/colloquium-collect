# 뉴스 실험실 (기사 고르기 감각을 룰북으로 옮기는 곳)

2026-11-14 의장(기자 25년)이 만든 실험 공간입니다. 07시 자료수집과 따로 돕니다.

## 매일 흐름
1. **06:30** GitHub Actions '뉴스 실험실'이 무료 통로에서 24시간 기사를 모읍니다.
   - 외신: 블룸버그 공식 RSS(제목+짧은 요약), CNBC RSS, AP·CNN(GDELT 무료 색인)
   - 국내: 연합뉴스·매일경제·조선일보 RSS, 네이버 검색 API(키가 있으면, 외신 번역 기사 → 보강용)
   - robots.txt가 막은 주소는 건너뜁니다. 기사 본문은 긁지 않습니다(제목·요약·링크만).
2. 제미나이가 `룰북.txt`와 의장 판정 사례를 읽고 후보 약 25건을 고릅니다(쓸 것/버릴 것, 이유 한 줄, 같은 사건 다른 보도 묶기).
   503·429면 기다렸다 다시, 다른 모델로 한 번 더, 그래도 안 되면 키워드 규칙으로 고르고 '제미나이 실패'라고 적습니다.
3. 결과: 드라이브 `콜로키움 수집데이터/뉴스실험실/YYYYMMDD_후보.csv`(후보), `_전체.csv`(모은 기사 전부), `_정보.json`
4. 의장은 스트림릿 **뉴스 고르기** 화면에서 쓸 것/버릴 것과 이유 한 줄을 표시 → `YYYYMMDD_판정.csv`, `00_판정누적.csv`
5. 다음 날 제미나이가 누적 사례(특히 의장이 다르게 고른 것)를 읽고 따라 고릅니다.
6. 2~3주 쌓이면 클로드가 이유를 묶어 `룰북.txt`를 고치고, 의장이 머지하면 반영됩니다.

## 손으로 돌리기
GitHub → Actions → **뉴스 실험실** → Run workflow (`hours` 칸에 몇 시간 안 기사를 모을지)

## 키(GitHub Secrets)
GEMINI_API_KEY(있음), DRIVE_URL·DRIVE_TOKEN(있음), NAVER_CLIENT_ID·NAVER_CLIENT_SECRET(없으면 네이버만 건너뜀)
