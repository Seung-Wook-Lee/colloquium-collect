# 차트 실험실 (보조지표만으로 하는 기술적 분석 실험)

2026-11-13 의장님이 만든 실험 공간입니다. 팀 Q(금융공학 종합, `team_q` 저장소)와 따로, **보조지표만으로** 바닥·꼭지·추세 조건을 시험합니다. 미스 차트 룰 후보를 여기서 먼저 시험합니다.
계산은 GitHub Actions에서 돌고, 결과 csv는 드라이브에 쌓입니다.

## 실험 돌리는 법
1. GitHub → Actions → **차트 실험실 실행** → Run workflow
2. `실험` 칸에 실험 파일 이름(예: `macd_daily_band`). 여러 개는 띄어쓰기로.
3. 결과: 드라이브 `콜로키움 수집데이터/차트실험실/<실험 이름>/`
   - `_요약` 규칙별 1·3·6달 뒤 수익률 중앙값, 지수 대비, 오른 비율, **아무 날 대비**, 건수, 앞·뒤 절반 비교
   - `_층별` 시장·층별 같은 표
   - `_사건` 신호 하나하나
   - `_지금신호` 마지막 5봉 안에 켜진 신호
   - `_설명` 정의·기간·설정 원문

## 실험 하나 = 설정 파일 하나 (`experiments/<이름>.yaml`)
```yaml
제목: 일봉 MACD ±선으로 바닥·꼭지 잡기
기본봉: 일봉          # 일봉(1·3·6달 = 21·63·126봉) | 주봉(4·13·26주) | 월봉(3·6·12달)
자료: 한투            # 한투 = 드라이브 한투 창고(일봉 10년·주월봉 20년) | 야후
시작: 2010-01-01      # (선택) 이 날 뒤 신호만
대상: {시장: [미국], 층: [S2, S3], 구분: [개별주], 제외: [TSLA]}   # (선택) 비우면 콜로키움 100 전부(현금성 ETF 제외)
중복제외봉: 10        # (선택) 같은 종목에서 이 봉 수 안에 다시 켜지면 세지 않음
규칙:
  - 이름: B1_바닥_골든크로스_MACD<-1.7%
    구분: 의장기준      # 의장기준 | 제안(Claude가 고른 숫자) | 비교
    조건:              # 줄마다 '그리고'
      - d.macd_pct < -1.7
      - cross_up(d.macd_osc, 0)
    기록: [macd, macd_pct]   # (선택) 사건 표에 같이 적을 지표
```
- `d.` 일봉, `w.` 주봉, `m.` 월봉. 주봉·월봉은 **그날까지 끝난 봉 값**(미래를 보지 않음).
- 한 줄 안에서 `&`(그리고), `|`(또는)를 쓰면 괄호로 묶습니다: `(d.rsi < 30) | (d.cci < -100)`

### 지표 이름
| 이름 | 뜻 |
|---|---|
| `open high low close volume` | 시가·고가·저가·종가·거래량 |
| `ma5 ma10 ma20 ma50 ma60 ma120 ma200` | 이동평균 |
| `disp5 … disp200` | 이격도(100 기준, 종가÷이평×100) |
| `macd macd_sig macd_osc` | MACD 12·26·9(EMA), 시그널, 오실레이터(막대) |
| `macd_pct osc_pct` | MACD·오실레이터 ÷ 종가 × 100 (종목끼리 비교용) |
| `rsi rsi_s` | RSI 14 와일더식(판정), 단순평균식(미래에셋 차트) |
| `cci` | CCI 20 |
| `stoch_k stoch_d` | 스토캐스틱 슬로우 14·3·3 |
| `bb_up bb_mid bb_dn bb_pctb bb_width` | 볼린저 20·2, %B, 폭(%) |
| `tenkan kijun span_a span_b cloud_top cloud_bot` | 일목 9·26·52 (구름은 오늘 자리 기준) |
| `dd252 dd_all` | 252봉 고점 대비·전체 고점 대비 하락(%) |
| `chg body lower_tail upper_tail vol_ratio` | 한 봉 등락(%), 몸통(%), 아랫·윗꼬리 비율, 거래량÷20봉 평균 |

### 도우미
`cross_up(a, b)` a가 b를 위로 넘음 · `cross_down(a, b)` · `turn_up(a)` 줄다가 늘기 시작 · `turn_down(a)` · `rising(a, n)` n봉 연속 상승 · `falling(a, n)` · `prev(a, n)` n봉 전 값 · `within(조건, n)` 지난 n봉 안에 한 번이라도 · `pctl(a, 750, 250)` 지난 750봉 안 백분위(0~100)

## 원칙
- 의장 기준을 먼저 **그대로** 시험(주가 수준이 다르면 비율로 환산하고 설명에 적음). Claude가 고른 숫자는 `구분: 제안`.
- 통계는 중앙값. 30건 미만은 판단하지 않음. 기간 앞·뒤 절반에서 같은 쪽인지 보고 과최적화를 경계.
- 패턴 판정(이중 바닥·넥라인 등)과 손절가는 넣지 않음.
- 자료는 읽기만(드라이브 한투 창고). 비밀값은 자료수집과 같은 `DRIVE_URL`·`DRIVE_TOKEN`.
