유튜브 → 위원 공부자료 (2026-11-14)

1. 하는 일
- 의장 추천 영상과 정기 채널의 새 영상을 제미나이 API에 주소째 넘겨 받아 적습니다(영상을 내려받지 않음, 무료 한도 안, 비용 0원).
- 결과 txt: 위원_유튜브_채널_제목_게시일.txt (RAG 형식, 종류 '유튜브')
  드라이브 '콜로키움 수집데이터/유튜브/위원공부_유튜브/' 와 저장소 youtube-data 브랜치 youtube/out/
- 작업 창은 그 txt를 /mnt/project-files/위원공부/유튜브/ 로 복사한 뒤 python rag/build.py

2. 의장이 링크 넘기는 법(셋 중 편한 것)
- 채팅에 주소를 붙이면 클로드가 youtube/링크.txt에 넣습니다.
- 드라이브 '콜로키움 수집데이터/유튜브/링크.txt' 에 한 줄에 하나.
- GitHub Actions → 유튜브 공부자료 → Run workflow 칸에 주소(바로 실행).
  줄 모양: 주소 [위원] [메모]. 위원을 비우면 제미나이가 고릅니다.

3. 정기 채널: youtube/채널.csv (이름, 채널(@핸들 또는 UC… id), 위원, 제목에_꼭(예: 마감|시황), 켜기, 메모)
- 매일 08:30·21:00(한국) 채널 RSS로 최근 3일 새 영상을 찾습니다. 쇼츠는 뺍니다.

4. 지키는 것
- 영상 속 말만 옮기고 [사실]/[출연자 의견]을 나눕니다. 제미나이 판단·매매 의견 없음.
- 영상 숫자는 출연자 말이라 그날 판정에 쓰지 않습니다.
- 일본 유튜브는 제이미 몫: 위원 '아야카상'이거나 영상 언어가 일본어면 건너뜁니다.
- 503·429는 30·60·120·240초 기다렸다 다시, 그래도 안 되면 다음 모델(3.5-flash-lite → 3-flash-preview). 실패한 영상은 다음 실행 때 다시(최대 3번).
- 40분이 넘는 영상은 30분씩 나눠 받아 적고 맨 위 요약을 다시 씁니다. 한 번에 최대 8개.
- 처리한 영상은 처리목록.csv 에 남아 두 번 하지 않습니다. 영상마다 쓴 토큰(토큰 칸)과 길이(길이분 칸)도 남깁니다.
- 토큰: 화면은 10초에 한 장만(fps 0.1) 보고 소리 위주로 받아 적어 토큰이 약 1/3. 시험값 2분 반 영상 4,700토큰 → 30분 영상 약 6만 토큰. 제미나이 무료 한도 안이라 돈은 0원, 클로드 토큰은 쓰지 않음(GitHub에서 돎).
