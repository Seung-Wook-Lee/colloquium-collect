# 퀀트센터 질문 블록 엔진 (2026-11-16)

블록 하나 = 질문 하나, 블록 안 = 그 답을 내는 공식 전부. 공식 추가·삭제는 `blocks.yaml` 한 줄.

- `features.py`: 07시 수집 파일 + `in/` 보조 자료로 종목당 한 줄의 칸을 만든다.
- `engine.py <자료 폴더>`: 시장 블록 B01~B08, 종목 블록 B09~B25, 엔진 계산 B26 분할·B27 비중 상한·B28 매도 신호 → `out_판정표.csv`·`out_공식별결과.csv`·`out_시장블록.csv`.
- 추천: 거르기(B09~B12) 통과 후 점수·타이밍·핵심 블록마다 공식 과반 = 예, 예 2/3 이상 추천·1/2 이상 관찰(개별주 최소 8블록, ETF 6블록).
- ETF는 보유 상위 10종목(`ETF보유.csv`, `ETF멤버.csv`)의 이익·전망·재무·밸류를 보유 비중 가중 평균.
- `fetch_*.py`: 야후·DART 보조 자료 수집. `fetch_per3.py`: 자기 3년 PER 밴드.
- `gen7.py`·`gen_blocks.py` + `topdf.js`(Node Playwright): 추천 보고서·블록 구성 PDF.

## 11/19 추가: 순서·합산·메타·완성도
- `blocks.yaml` **순서**: 블록 계산 뒤 단계를 이 순서대로 실행(거르기 → 합산 → 판정 → 메타). 모르는 단계나 앞 단계가 빠지면 엔진이 멈추고 이유를 출력.
- **합산** (`combine.py`, Carver pysystemtrade): 블록 점수를 ±10 눈금으로 맞추고 가중평균 × 분산 승수(블록끼리 상관이 낮을수록 큼, 상한 2.5). 판정 기준 `추천.기준: 종합점수`(문턱은 기존 추천선·관찰선과 같은 뜻으로 환산).
- **메타** (`meta.py`, 로페즈 데 프라도 메타라벨링): 1차 신호(추천·관찰)를 `추천기록/신호장부.csv`에 매일 쌓고, 20거래일 트리플 배리어로 정답을 붙여, 확정 정답 200개가 쌓이면 '이 신호를 믿을 확률' → 비중 배수. 그 전에는 배수 1. 시장 블록 B01~B08의 부담·기회 개수가 2차 판정 입력.
- **완성도** (`audit.py <입력 폴더>` → `out_블록완성도.csv`, `out_공식완성도.csv`): 채움률(범위 밖은 해당 없음)·과거 계산 등급·칸 존재·역할 일치. 시험: `pytest tests/test_quant_center.py`.

## 매일 실행
1. 07시 수집 파일(드라이브 '콜로키움 수집데이터' 오늘 폴더)을 입력 폴더(/mnt/project-files/퀀트센터/입력/)에 같은 이름(시세.csv, 닉스.csv, 국내수급.csv …)으로 받는다. 보조 자료(가격2년·지수2년·재무·ETF보유·PER3년)는 fetch_*.py로 갱신.
2. `python engine.py <입력 폴더>` → 판정표. `python gen7.py` → 오늘의 추천 종목 HTML, `node topdf.js` → PDF.
